01 Visão Geral do Ciclo de Dados

O FinanceApp opera integrando a API Open Finance da Pluggy com um banco de dados local MySQL, garantindo velocidade de carregamento e persistência das informações financeiras.

02 Fluxo de Funcionamento (Step-by-Step)

1.

Autorização do Usuário (Widget)

O usuário inicia a conexão via Pluggy Connect Widget no navegador. Ao finalizar a autenticação no banco, o Widget gera um Item_ID exclusivo.

2.

Gatilho de Sincronização

O navegador envia este ID para a rota do servidor Laravel (POST /pluggy/sync). O servidor entra em modo de espera para processar a coleta.

3.

Busca e Persistência (Back-end)

O PluggyService consome a API REST da Pluggy buscando Contas e Transações. Os dados são convertidos e salvos no MySQL através dos modelos BankAccount e Transaction.

4.

Renderização do Dashboard

Com os dados locais atualizados, o DashboardController extrai os saldos e o extrato do MySQL para exibição instantânea na interface.

03 Mapa de Responsabilidades dos Arquivos
